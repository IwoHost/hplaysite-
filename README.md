# Hplaysite

The site for [Hplay](https://iwohost.github.io/hplaysite/), a click-wheel music
player for your own files, built by HostLabo.

Plain HTML and CSS, no framework and no build step, served by GitHub Pages
straight from `main`.

| Path | What it is |
|------|------------|
| `index.html` | The site |
| `review.html` | A long read on how the player got built |
| `feedback.html` | The alpha feedback form, English and Polish |
| `img/` | Screenshots, album sleeves and photos |
| `music/` | The twenty demo tracks, plus a zip of all of them |

## The demo music

Twenty tracks on six invented compilations, released as HostLabo Tapes. They
were written and synthesised from scratch to give the player something varied
to be tested against. No real artist, band or recording is involved, and every
name and sleeve is made up. Free to download and keep.

## The player

Hplay itself is not in this repository. It is in a closed alpha and is handed
out one person at a time: hostlabosupport@gmail.com.
